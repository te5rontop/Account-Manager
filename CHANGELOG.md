# Changelog

All notable changes to Account Manager will be documented in this file.

## [1.0.0] - 2026-09-02

### Added

- Initial public release.
- Microsoft sign-in through the system browser.
- Account Manager button on the Multiplayer screen.
- Microsoft and Minecraft authentication status display.
- Minecraft profile viewer with IGN, UUID and skin preview.
- Manual Minecraft profile refresh.
- Skin PNG chooser and 64x64 validation.
- Classic and Slim skin model preview.
- Minecraft skin upload integration for authorized Minecraft Services sessions.
- Minecraft IGN change integration for authorized Minecraft Services sessions.
- Custom Account Manager, Profile Management, Skin Management and IGN Editor screens.
- In-memory authentication state handling.
- Moving Discord watermark and project branding.

### Known limitation

- New third-party Minecraft Java Edition API integrations require Minecraft Services allow-list approval. Until the application's Client ID is approved, profile-service features may show `App Not Authorized`.
